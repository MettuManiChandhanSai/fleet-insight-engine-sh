## 🚀 AFTER DOWNLOADING - Quick Start

### 1. Extract Files
```bash
unzip fleet-insight-engine.zip
cd fleet-insight-engine
```

### 2. Install Dependencies
```bash
pnpm install
```

### 3. Create Environment File
Create `.env.local` in project root:
```
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_PUBLISHABLE_KEY=your_supabase_key
OPENAI_API_KEY=your_openai_api_key
```

### 4. Start Development Server
```bash
pnpm dev
```

### 5. Open in Browser
Visit: **http://localhost:5173**

### 6. Login
Use the same credentials as the live version

## 🔑 API KEYS NEEDED (For Local Development)

**OpenAI:**
- Go: https://platform.openai.com/api-keys
- Create new secret key
- Add as: `OPENAI_API_KEY` in `.env.local`

**Supabase:**
- Go: https://supabase.com
- Create project or select existing
- Copy Project URL → `VITE_SUPABASE_URL`
- Copy Anon Key → `VITE_SUPABASE_PUBLISHABLE_KEY`

**Note:** Live version already has these configured!
